# projetao_ia
Trabalho desenvolvido para a disciplina de Inteligência Artificial do PPGI 2026.2, disciplina ministrada pelos professores Evandro Barros e Xu Yang.
### Projeto desenvolvido para a disciplina de inteligência artificial do ppgi 2026.2
##### conteúdo:
### Relatório com até 10 páginas) contendo:

arquitetura e papel de cada agente;

como os agentes cooperam e resolvem conflitos;

resultados nos casos de teste;

resposta à pergunta central: o que cada paradigma trouxe de único.

Código executável com README e a base de casos.

Demo de 10 min com um caso completo, incluindo um conflito entre agentes.

Casos

Cada grupo cria sua própria base de casos sintéticos (mínimo de 10). A base deve:

incluir casos fáceis, ambíguos e com dados faltantes;

ter ao menos 2 casos em que os agentes discordam;

vir com o gabarito esperado e a fonte dos protocolos usados.

Requisitos mínimos

Os quatro agentes devem estar presentes:

regras, que explica pelo rastro de regras disparadas;

Rede Bayesiana, que explica pelas probabilidades;

LLM, que justifica com base nos protocolos fornecidos;

neuro-simbólico, que combina de fato os dois mundos. Exemplo: o LLM extrai fatos estruturados e um motor de regras valida e infere sobre eles. Chamar o LLM e depois aplicar um if não conta.

Um teste de ablação: o que muda quando cada agente é removido.

Declaração de uso de LLM (obrigatória)

No sistema: qual modelo foi usado, para quê e como as saídas são verificadas.

No desenvolvimento: se usaram IA para código, texto, criação de casos ou base de regras, e em que medida revisaram o resultado.

Limitações observadas: alucinações, inconsistências e como lidaram com elas.

Avaliação

Sistema: 50%

Experimentos e análise: 40%

Demo: 10%
